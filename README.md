# TindAI

**Human or AI? You have five minutes to find out.**

TindAI is a social experiment and AI-literacy game built around a swipe-and-match interaction. Participants know the network contains both humans and synthetic characters, but identity is revealed only after a timed conversation.

## V1 roadmap
- Original mobile-first discovery UI and first-use walkthrough
- Authentication, profile editor, interests and discovery criteria
- Multi-photo upload, preview, reorder and delete
- Swipe/match engine
- 5-minute realtime challenge
- Human/AI vote + reveal
- AI literacy score and post-chat insights
- Reporting, blocking, 18+ gate and synthetic-identity safeguards

## Stack
Next.js App Router + TypeScript, Supabase Auth/Postgres/Storage/Realtime, deployed on Vercel.

## Status
Phase 1: interface foundation. Database/auth wiring is the next milestone.
